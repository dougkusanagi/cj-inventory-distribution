# ADRs

ADR significa Architecture Decision Record.

Use esta pasta para registrar decisões importantes que expliquem por que o sistema foi estruturado de determinada forma.

Formato sugerido:

```text
# ADR 000X — Título

## Status

Accepted

## Contexto

Qual problema precisava ser resolvido?

## Decisão

O que foi decidido?

## Consequências

Quais vantagens, limitações e impactos surgem dessa decisão?
```
