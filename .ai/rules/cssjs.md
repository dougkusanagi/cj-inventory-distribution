# Cssjs

## Separate action, brand, and feedback colors
Use `--action` for the yellow primary CTA (`--primary` is its shadcn alias), `--brand-expressive` for the earthy institutional red, and `--destructive` only for errors/deletion with a distinctly purer red. Light and dark neutrals must use theme-specific values; normal text and highlight target WCAG AA 4.5:1, while input borders and UI affordances target at least 3:1.
